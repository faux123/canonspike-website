faux123 YT learn

faux123 YT learn is a private tool that Paul Reioux runs on his own computer to study how his own YouTube channel, faux123, performs. It is not offered to anyone else, and nobody else can sign in to it.

Privacy

Last changed 2026-11-10.

  • The tool signs in only to the faux123 channel, with the channel owner's consent.
  • It reads that channel's own analytics (views, watch time, impressions, click-through rate, traffic sources, retention) and the channel's own video titles, descriptions, and tags.
  • It can update the titles, descriptions, and tags of faux123's own videos.
  • It never reads other people's accounts, private messages, or viewer identities.
  • Everything it reads is stored only on the owner's own computer. It is not sold, shared, or sent to anyone else.
  • The sign-in can be removed at any time from Google account permissions.

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.
